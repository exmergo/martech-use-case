# MarTech Viz Prompts

## 1. Marketing Performance Overview

Use mart_campaign_attribution.csv.

Create an executive marketing performance dashboard.

Show KPI cards for:
- Total Spend
- Total Conversions
- Total Revenue
- Overall CAC
- Overall ROAS

Then create a campaign comparison view showing:
- Campaign Name
- Channel
- Spend
- Revenue
- Conversions
- ROAS

Make it easy to compare Google Ads and Meta Ads campaigns.

## 2. Paid Media Performance

Use mart_paid_ads_performance.csv.

Create a time-series dashboard showing daily:
- Spend
- Clicks
- Conversions

Compare Google Ads and Meta Ads using the channel field.

Also include:
- CTR
- CPC
- CPM
- Conversion Rate

Use date as the time dimension.
Make channel and campaign_name available as filters.

## Goal

Help a marketing stakeholder understand:
- how much was spent,
- which campaigns generated the most revenue,
- which campaigns have the strongest ROAS,
- customer acquisition cost,
- and how paid-media performance changes over time.
